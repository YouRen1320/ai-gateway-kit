# Support

## Questions and deployment help

Use GitHub Discussions when enabled. Before asking for help:

1. Read both README and the relevant document under `docs/`.
2. Run `./bin/doctor`.
3. Reproduce the problem without customer data.
4. Include the kit version, operating system, Docker/Compose versions, image tags and digests, and the failing command.

Do not include `.env`, credentials, database files, raw production logs, prompts, outputs, customer identifiers, or private infrastructure details.

## Bugs

Use the bug issue form and include a minimal synthetic reproduction. Provider-account suspension, unsupported provider terms, upstream service availability, and custom product integrations are outside this project's support scope.

## Security issues

Follow [SECURITY.md](SECURITY.md). Never report a vulnerability containing live credentials through a public issue.
